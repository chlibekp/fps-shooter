# Map gameplay definitions

Each `<map>.json` describes the **gameplay geometry** of a map. It is loaded by
the Rust server (collision, spawns) and by the Unreal client (prediction
collision and the graybox/blockout). Visual art is layered on top in Unreal.

Coordinates: meters, Z-up, X forward, Y right (see ARCHITECTURE.md, decision 7).

```json
{
  "name": "test_arena",
  "kill_z": -30.0,
  "solids": [
    { "min": [x, y, z], "max": [x, y, z], "material": "concrete", "tag": "floor" }
  ],
  "spawns": [ { "pos": [x, y, z], "yaw": 0.0, "team": 0 } ],
  "objectives": [ { "name": "Archives", "min": [x, y, z], "max": [x, y, z] } ]
}
```

* `material`: `concrete`, `brick`, `wood`, `drywall`, `metal`, `glass`,
  `reinforced`, `dirt`.
* `tag`: free text used by the client for visuals (`floor`, `wall_*`,
  `crate`, `stairs`, ...).
* Spawn `pos` is the feet position. Team 0 = attackers, team 1 = defenders.
* `objectives` (optional): named objective sites for game modes. They are
  not part of the geometry hash yet (game modes arrive in Phase 6).

The server sends a 64-bit FNV-1a hash of the solids (min/max float bits +
material) and `kill_z` in `ConnectAccepted`. The client computes the same hash
from its copy and refuses to play on a mismatch.

## Maps

| File | Name | Size | Objective sites |
|------|------|------|-----------------|
| `test_arena.json` | Test Arena (graybox for development) | 48 × 48 m | – |
| `harbor.json` | Harbor Warehouse | 84 × 68 m | Upper Office, Storage |
| `villa.json` | Hillside Villa | 80 × 66 m | Master Bedroom, Basement |
| `consulate.json` | Consulate | 68 × 72 m | Archives, Ambassador Office |

Every JSON is generated by a script in `Tools/MapTools` (`build_<map>.py`,
all of them via `build_all.py`). Edit the script, not the JSON: CI
regenerates the maps and fails on any difference. The production maps use
`Tools/MapTools/mapkit.py`:

* walls split into panels of at most 2.4 m (the unit of reinforcement);
* doors and windows cut out of walls, with breakable doors, glass and
  plank barricades;
* floors with holes and breakable hatches;
* stairs with steps of at most 0.25 m.

`Shared/Simulation/rust/tests/maps.rs` validates every map:
* spawns are free and on the ground;
* there are at least 5 spawns per team and 2 objective sites;
* each defender spawn can walk to every site with the map intact;
* the attackers can reach every site through breachable surfaces.

The test walks a 0.25 m grid with the real player box, steps, jumps and
crouching.
